# IceGod 前端设计规范

方向：**升级**——保留原有后台信息架构与组件，统一品牌为 IceGod，收敛配色与层级，让数据优先、装饰最少。

## 配色角色

| 角色 | 变量 | 用途 |
| --- | --- | --- |
| 主色 | `--theme-primary-*`（预设 `glacier` 冰川蓝，默认） | 主按钮、链接、选中态、KPI 竖条与图标 |
| 页面底 | `--ig-bg` | `body` 背景，浅色冷灰 / 暗色深蓝黑 |
| 表面 | `--ig-surface` | 卡片、侧栏、KPI 卡 |
| 分割线 | `--ig-line` | 卡片边框、卡片头分割 |
| 正文 | `--ig-ink` | 数值、标题 |
| 次要文字 | `--ig-muted` | 标签、提示、说明 |

规则：
- 一屏只有主色一种饱和色；状态色（成功/警告/错误）只用于状态徽章与提示，不用于大块数字。
- 数字统一用 `--ig-ink` + `tabular-nums`，不再给每个统计数字配不同颜色。
- 暗色模式只替换 `--ig-*` 与主色深浅档，组件结构不变。

## KPI 卡（`.kpi-card`）

- 结构：`.kpi-label`（13px，muted）+ `.kpi-icon`（28px 圆角方块，主色 50 底）→ `.kpi-value`（28px / 650 字重）→ 可选 `.kpi-hint`（12px）。
- 左侧 3px 主色竖条，圆角 10px，1px `--ig-line` 边框，不加阴影。
- 仪表盘首屏只放 4 张核心卡（账号总数、启用账号、今日回复、订单总数），其余指标降级为下方一条信息带。
- 移动端两列，桌面四列。

## 导航选中态（`.ig-nav-active`）

- 浅主色底（primary-50）+ 主色 700 文字 + 600 字重 + 左侧 3px 内阴影竖条。
- 暗色：primary-900/50 底 + primary-200 文字。
- 不再使用整块饱和主色背景。

## 品牌

- 名称统一为 `IceGod`；图标为 `components/common/BrandMark.tsx` 中的冰晶 `BrandMark` / `BrandLogo`。
- 登录、注册、找回密码左侧品牌区用 `.ig-auth-hero` + `.ig-auth-grid`（深蓝渐变 + 淡网格），不加装饰圆或插画。
- 设置页“登录页预览”与实际登录页使用同一组样式。
